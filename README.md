# 🎫 Event & Digital Ticket Management Platform

> Multi-tenant digital event management & ticketing system built with Node.js, TypeScript, Clean Architecture, Prisma, and PostgreSQL.

---

## 📌 About The Project

Platform manajemen event dan tiket digital skala enterprise yang mendukung multi-organizer (multi-tenant). Dirancang menggunakan arsitektur **Clean Architecture Modular** untuk memastikan skala, keamanan, dan kemudahan pemeliharaan (*maintainability*).

---

## 🏗️ Repository Structure (Monorepo)

```
.
├── 📁 backend/     # Express.js + TypeScript + Prisma ORM + PostgreSQL
└── 📁 frontend/    # Frontend App (Coming Soon)
```

---

## 🚀 Tech Stack (Backend)

- **Language**: TypeScript
- **Runtime**: Node.js
- **Framework**: Express.js
- **ORM**: Prisma
- **Database**: PostgreSQL
- **Architecture**: Modular Clean Architecture
- **Infrastructure**: Docker & Docker Compose

---

## ⚡ Quick Start (Backend)

1. Clone repository:
   ```bash
   git clone <your-repo-url>
   cd <repo-name>
   ```

2. Masuk ke folder backend:
   ```bash
   cd backend
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Jalankan development server:
   ```bash
   npm run dev
   ```
